# 困难集视觉抽样审计

日期：2026-11-16

本次对 `contact_sheets/cross_tile_proxy.png`、`low_pixel_mass.png` 和 `ranker_missed.png` 做了视觉抽样。审计只检查现有图像、掩膜叠加和自动标签，不修改原始图像、掩膜或困难集清单，也不把抽样观察当作人工金标准标注。

## 观察结果

- `low_pixel_mass` 中可见多类真实细裂纹：单像素到数像素宽、低对比度、贴近构件边缘或接缝的裂纹均有出现；同时存在难以仅凭当前缩略图区分的表面纹理、接缝线和构件边缘。
- `cross_tile_proxy` 中部分样本在固定边界两侧呈现方向连续的裂纹，具有人工复核价值；另一些样本更像结构接缝、金属边界或断续纹理。该代理只能说明标注像素靠近同一固定接缝两侧，不能自动证明是同一条跨块裂纹。
- `ranker_missed` 中有可见的极细或低对比裂纹，说明一级漏选并非全是空白误报；但缩略图也无法排除部分样本受背景纹理或标注边界影响。

## 决定

困难集的自动类别继续作为筛选索引，`review_status` 保持 `needs_manual_review`。不根据本次抽样自动修改标签，不把 `edge_touch_proxy` 或 `cross_tile_proxy` 改名为真实跨块、弯曲或分叉类别。后续需要在原始 512×512 或完整 2048×1536 分辨率下进行人工形态标注，并为人工标签记录审阅者、规则、版本和争议样本。
