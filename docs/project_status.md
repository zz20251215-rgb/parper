## 最新一级适配：evidence已停止

`MobileNetV3SmallEvidenceGridRanker` 在多阶段全局avg/max之外保留1/8阶段2×2局部avg/max，再使用3×4位置编码和两层3×3邻域卷积。smoke后完成30轮正式训练，最佳第10轮；块级top-6 Recall验证83.72%、测试开发75.00%，均未超过grid的86.05%/91.67%。

## 导出状态与更正

`deploy/refine_fp32.ts` 的CPU单输入导出、单块基准及历史级联指标接近，只说明相应测试范围内的结果。2026-11-17用独立加载的eager/JIT模型顺序测试3个固定随机输入和1个真实验证块：CPU四项最大差均为0；CUDA第一项为0，后续最大logit绝对差为0.28264、0.28641、0.91796，严格 `assert_close(rtol=1e-5, atol=1e-6)` 失败，输出均有限。本次4个输入的二值掩膜差异为0，不能由此证明全数据或其他batch一致。该检查为batch=1，未完成更广验收，差异根因未定位。

独立FP16尝试保存重载后也未通过多输入校验，历史最大差约4.48。失败文件保留在 `deploy/independent_fp16_attempts/`。运行时 `.half()`、eager FP16和独立FP16文件的报告分别留档，不能相互替代；此前“修复成功”“唯一默认FP32 TorchScript”及“差异仅由阈值边界产生”的结论撤回。默认质量对照为eager FP32；ONNX、INT8和目标设备验收未完成。
